# Portfolio Project (Decoupled Fullstack with Supabase)

Proyek ini menggunakan arsitektur **terpisah (*decoupled*)**:
- **Frontend Service**: React + Vite (`frontend/`) berjalan mandiri di port `5173`.
- **Backend Service**: Node.js + Express (`backend/`) berjalan mandiri di port `5001`.
- **Database**: PostgreSQL di **Supabase Cloud**.

---

## 1. Setup Database di Supabase
1. Buka [supabase.com](https://supabase.com) dan buat project baru.
2. Masuk ke **SQL Editor** di dashboard Supabase dan jalankan skrip berikut:

```sql
CREATE TABLE IF NOT EXISTS public.messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) NOT NULL,
  message TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Aktifkan Row Level Security (RLS)
ALTER TABLE public.messages ENABLE ROW LEVEL SECURITY;

-- Policy untuk insert dan select
CREATE POLICY "Allow insert messages" ON public.messages
  FOR INSERT WITH CHECK (true);

CREATE POLICY "Allow read messages" ON public.messages
  FOR SELECT USING (true);
```

3. Masuk ke **Project Settings -> API** untuk menyalin:
   - **Project URL**
   - **anon key** atau **service_role key**

---

## 2. Cara Menjalankan Layanan

### Menjalankan Backend Service (Terminal 1)
```bash
cd backend
npm install
```
Isi kredensial Supabase di `backend/.env`:
```env
PORT=5001
CLIENT_ORIGIN=http://localhost:5173
BASE_URL=http://localhost:5001

SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-key
```
Jalankan server backend:
```bash
npm run dev
```
Backend aktif di `http://localhost:5001`.

---

### Menjalankan Frontend Service (Terminal 2)
```bash
cd frontend
npm install
npm run dev
```
Frontend aktif di `http://localhost:5173`.
Pesan kontak dari frontend akan langsung terkirim ke Backend dan tersimpan aman di database Supabase cloud.
